# Naina's Shop - Mobile Web Extension

A mobile-optimized browser extension for Naina's Shop with Sasuke-inspired smokey purple theme.

## Features

✨ **Mobile-First Design**
- Responsive layout optimized for mobile devices (< 480px width)
- Touch-friendly buttons and interactions
- Smooth animations and transitions

🎤 **Product Showcase**
- Display multiple microphone products
- Individual product cards with pricing
- Quick "View Details" actions

🛒 **Shopping Cart**
- Add items to cart functionality
- Persistent storage using Chrome storage API
- Cart notifications

⚙️ **Settings Page**
- Customizable store information
- Notification preferences
- Theme options (including dark mode)

📱 **Mobile Optimizations**
- Safe area support (notch, etc.)
- Optimized for touch (no hover delays)
- Minimal data usage
- Fast performance

## Installation

1. Open Chrome and go to `chrome://extensions/`
2. Enable "Developer mode" (top right)
3. Click "Load unpacked"
4. Select the `Naina-shop-extension` folder
5. The extension icon will appear in your toolbar

## File Structure

```
Naina-shop-extension/
├── manifest.json      # Extension configuration
├── popup.html         # Main popup interface
├── popup.js          # Popup functionality
├── styles.css        # Mobile-optimized styling
├── options.html      # Settings page
├── options.js        # Settings functionality
└── README.md         # This file
```

## Usage

1. Click the extension icon to open the popup
2. Browse available microphones
3. Click "View Details" to see contact details
4. Customize settings in the options page

## Browser Compatibility

- Chrome 90+
- Edge 90+
- Opera 76+
