# Naina's Shop — Chrome Web Store Listing

Title: Naina's Shop — Mobile Microphone Popup
Short description: Mobile-optimized extension showcasing Naina's mic collection with quick contact details.

Full description:
Naina's Shop is a lightweight, mobile-first browser extension that displays a curated microphone collection and provides quick contact details. It features a smokey purple theme, touch-friendly UI, and a simple "View Details" modal that shows contact email and Discord server info.

Features:
- Mobile-optimized popup UI
- Touch-friendly product cards
- Prices in Indian Rupees
- View Details modal with contact email and Discord server
- Lightweight, privacy-friendly (no external tracking)

Assets to upload:
- icons/icon-128.png (128x128)
- icons/icon-48.png (48x48)
- icons/icon-16.png (16x16)
- screenshots/screenshot1.png (recommended: 640x480 or similar)

Privacy policy (short draft):
This extension does not collect personal data. It uses Chrome storage only to store optional user settings locally. Contact information displayed in the extension is static and provided by the developer. No analytics or remote servers are used.

Publishing notes:
1. Create a Chrome Web Store developer account (one-time $5 fee).
2. Prepare a ZIP of the extension root (this repository already contains one: `Naina-shop-extension.zip`).
3. Upload icons and at least one screenshot when creating the listing.
4. Paste the short and long descriptions and select visibility (Public/Unlisted).
5. Add the privacy policy URL if required (host a simple page or GitHub Pages URL).
